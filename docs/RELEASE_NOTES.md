# سيارتي — My Car 0.3.0-alpha

- Native Godot 4.7.2 driving experience with Jolt and the Compatibility renderer.
- Ten original vehicle IDs with differentiated suspension, drivetrain and chassis configuration.
- One connected 15 km corridor through six Yemeni regions, with streamed collision, local weather, terrain surfaces, traffic, a tunnel and a coastal bridge.
- Arabic touch controls, control layout editing, showroom, paint selection, six cameras and an offline route map.
- Five chapters with 25 checkpoint routes, six bonus activities, rewards, and automatic and manual local save handling.

The release target is Android 8.0 and later on arm64-v8a devices with GLES 3.0. A release APK requires the previous production key and certificate validation. The debug APK uses a development certificate.

Known limitations include procedural assets, a linear road network, route-based traffic, simplified audio and mission variants, and no verified Android frame-rate benchmarks. Device installation, sustained performance and airplane mode on physical hardware remain device acceptance gates.
